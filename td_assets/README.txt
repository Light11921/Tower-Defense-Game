Tower defense assets (all original, generated by make_assets.py)

Copy the "assets" folder and assets.py into your project folder (next to main.py).

  assets/towers   cannon, fire, ice, arcane     60x60  (barrels point up)
  assets/enemies  grunt, fast, tank (48x48), boss (64x64)
                  shield_physical / shield_fire / shield_ice  48x48 overlays,
                  draw on top of an enemy when it has adapted to that damage type
  assets/tiles    grass1, grass2, path, base, spawn, build_ok, build_bad   60x60
  assets/fx       bullet_cannon/fire/ice/arcane (16x16), explosion_0..5 (64x64)
  assets/ui       coin, heart, wave, play, pause, fast   32x32
  assets/sounds   shoot_*, hit, enemy_die, place_tower, sell, wave_start,
                  life_lost, adapt_alert, game_over, victory, click   (.ogg)
  assets/music    theme.ogg (9.6 second loop)

Usage in main.py, after pygame.display.set_mode(...):
  import assets
  images = assets.load_images()      # images["cannon"], images["grunt"], ...
  sounds = assets.load_sounds()      # sounds["shoot_fire"].play()
  assets.play_music()

Run "python make_assets.py" to regenerate everything (needs pillow, numpy and ffmpeg).
